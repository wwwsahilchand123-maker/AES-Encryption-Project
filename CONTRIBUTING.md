# Contributing to AES Encryption Project

This project is educational. Contributions should prioritize correct cryptographic usage, clear examples, and safe handling of secrets.

## Guidelines

- Never commit passwords, keys, plaintext private data, or generated secret material.
- Explain cryptographic assumptions when changing encryption or decryption code.
- Prefer standard, well-reviewed primitives and authenticated encryption where the project architecture supports it.
- Add tests for round-trip behavior and invalid-input handling.

## Pull requests

Include a summary of the change, tests run, and any compatibility or security considerations.
