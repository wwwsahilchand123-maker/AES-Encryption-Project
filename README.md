## 🧠 Overview

AES Encryption Project is a secure desktop application built with Python that provides file encryption and decryption using the Advanced Encryption Standard (AES).

## ✨ Features

- 🔒 AES-based file encryption
- 🔓 Password-protected file decryption
- 📂 File selection through GUI
- 📈 Encryption progress indicator
- ℹ️ File information display
- ✅ Input validation and error handling
- 🖥️ Simple desktop interface

## ⚡ Workflow

```text
Select File
    ↓
Enter Password
    ↓
AES Encryption
    ↓
Protected Output
    ↓
Password Verification
    ↓
AES Decryption
```

## 🛠️ Technology Stack

`Python` `Tkinter` `PyCryptodome` `AES` `File Handling`
