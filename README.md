# AES Encryption & Decryption System

A secure desktop application built with Python that provides file encryption and decryption using AES (Advanced Encryption Standard).

## Features

- AES-based file encryption
- File decryption using a password
- Password-protected file security
- File selection through GUI
- Encryption progress indicator
- File information display
- Error handling and validation
- Simple and user-friendly desktop interface

## Technologies Used

- Python
- Tkinter
- AES Cryptography
- PyCryptodome
- Python File Handling
